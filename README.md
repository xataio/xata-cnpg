# Xata CloudNativePG staging repository

This repository is a fork of the [CloudNativePG](https://github.com/cloudnative-pg/cloudnative-pg) 
repository. It is used as a staging area for Xata specific changes and improvements, but not meant
as a full fork. 

Our general intention is to propose these changes to the upstream project, but this allows us 
to move quicker and test the changes in our deployments. This gives us production experience with changes
while they are being discussed with the upstream project.

## Using

We don't recommend using this repository directly, but either:
* use the Xata platform, potentially with the BYOC option (see https://xata.io for details).
* wait for the changes to be upstreamed.

## Contributing

We generally recommend contributing upstream instead. If you do want to contribute to this repository, make
sure you discuss it with the Xata team first.
